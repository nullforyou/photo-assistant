## 摄像头打不开的修复（用户实测：除摄像头外其他正常）
- **根因**：`AndroidManifest.xml` 漏了 `<uses-permission android:name="android.permission.CAMERA" />`，且 `camera` 插件在 Android 上**不自动请求权限**，`initialize()` 在无授权时直接抛异常 / 卡住，相机页进不去。
- **修复**：① 清单加 CAMERA 权限；② pubspec 加 `permission_handler: ^11.4.0`；③ `shoot_page.dart` 的 `_initCamera` 开头先 `Permission.camera.request()`，未授权给提示，永久拒绝给"去系统设置"按钮（`openAppSettings()`）。
- 重打包 `app-release.apk` 成功并 `adb install -r` 装回手机 `YSE0222628002738`。
- 注意：iOS 版后续还需在 Info.plist 加 `NSCameraUsageDescription`（当前只做安卓）。

## 两个 UI 问题修复（用户实测反馈）
1. **拍照页看不到实时画面（但拍照能成图）**：根因是 `CameraPreview` 外面包了 `SizedBox.expand → FittedBox(fit:cover, child:CameraPreview)`。`CameraPreview` 底层是 `Texture`、无固有尺寸，`FittedBox` 量到 0 → 预览被缩成 0 大小全黑。`takePicture` 走帧缓冲所以仍能出图。修法：给 `FittedBox` 一个有固有尺寸的 child —— `SizedBox(width: controller.value.aspectRatio, height: 1, child: CameraPreview)`，标准 cover 全屏写法。
2. **拍照后点"重拍"一直转圈**：根因 `didChangeAppLifecycleState` 在 `AppLifecycleState.inactive` 就 `dispose()` 控制器；而页面内 `push` 预览页在某些安卓机型会触发 `inactive` → 控制器被销毁 → `pop` 回来时 `_controller==null` → 显示加载转圈。修法：只在 `paused`/`detached`（真正退后台）时释放；`resumed` 且 `_controller==null` 才重新初始化。

## 预览拉伸变形修复（竖屏画面被拉宽）
- 根因：预览 `SizedBox(width: controller.value.aspectRatio, height:1)` 里 `aspectRatio` 是摄像头**原始横屏**比例(如 1.78)，手机是**竖屏**显示；`SizedBox` 把 `Texture` 强行塞进横屏比例盒子 → 图像被拉宽变形（FittedBox.cover 只保证后续等比，不补救盒内拉伸）。
- 修法：竖屏时宽高互换，`boxRatio = isPortrait ? previewSize.height/previewSize.width : previewSize.width/previewSize.height`（用 `controller.value.previewSize` 计算最准，回退用 `aspectRatio`）。
- 注意：变量声明不能写进 `Stack` 的 `children:[...]`（必须是 Widget 表达式），要提到 `return` 之前算好再引用。
- 经验：`CameraPreview` 底层是 `Texture`、**无固有尺寸**，必须套比例正确的盒子，否则要么黑屏(0尺寸)要么变形。
