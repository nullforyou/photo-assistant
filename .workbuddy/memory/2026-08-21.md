## 当前进展
- 相机预览**拉伸变形**已修复：根因是给 `FittedBox` 套的 `SizedBox(width: aspectRatio, height:1)` 用了摄像头横屏原始比例，竖屏下把 Texture 拉宽。改法：用 `controller.value.previewSize` 计算显示方向真实比例（竖屏交换宽高），`FittedBox(cover)` 等比铺满不变形。
- 已重新 `flutter build apk --release` 成功（45.9MB），`adb install -r` 装回手机 `YSE0222628002738`，返回 `Success`。用户需验证预览不再变形。

## 用户新需求（待决策）
需求：点击拍照后**完全用手机自身相机**，App 只提供**透明蒙版**显示姿势虚线 + 一个切换姿势按钮（浮动展开可选姿势），蒙版不挡相机按键。
- 技术可行性：安卓/HarmonyOS 上**可行**，走 `SYSTEM_ALERT_WINDOW`（悬浮窗/显示在其他应用上）权限 + 前台 Service + `WindowManager.TYPE_APPLICATION_OVERLAY`。
  - 触摸穿透：根 View 设为不可点击透明层（触摸透传到底层相机），仅浮动按钮设为可点击 → 原生快门仍可点。
  - 权限：`SYSTEM_ALERT_WINDOW` 是特殊权限，需引导用户去设置手动开启（华为叫"悬浮窗/显示在其他应用上"），首次需授权。
  - 风险：华为/鸿蒙可能对相机 App 上叠悬浮窗有限制，需真机验证。
- 对比现状：当前 in-app 相机方案已具备「实时预览+虚线蒙版+姿势切换+拍照+保存」，功能等价，只是用的是 App 内置相机而非原生相机。新方案换来原生画质/快门，但架构更大、依赖悬浮窗权限。
- 待用户决策：① 先验证现有 in-app 方案（已修变形）；② 或转向「原生相机+悬浮蒙版」方案（Phase 2）。
