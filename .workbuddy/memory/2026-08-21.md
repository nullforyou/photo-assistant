## 核心功能技术方案：姿势引导拍摄（01:56）
- 需求：打开拍照 → 后置摄像头预览 → 取景框叠加虚线人形构图 → 底部一排姿势缩略图可切换 → 摆好姿势点快门。
- 结论：完全可行。一期纯引导（无 AI），二期可选 ML Kit 姿态检测做对齐评分。
- 技术选型：
  - 相机：官方 `camera` 插件（Android/iOS 成熟，web 可用；Windows 桌面版支持有限，演示建议用 Android 模拟器或 Chrome）。
  - 虚线人形：姿势定义为 JSON 关键点数据（骨架点+连线），`CustomPainter` + 虚线 Path 绘制，同一份数据同时渲染大图引导和底部缩略图。

  - 拍照：`controller.takePicture()` → XFile → 预览/保存。
- 关键实现点：姿势坐标用归一化值（0~1），按预览区宽高做等比缩放适配不同屏幕；拍照时引导线不进成片（图层分离，天然满足）。
- 二期：`google_mlkit_pose_detection`（33 关键点）→ 与目标姿势算角度相似度 → 对齐提示/自动连拍。

## Flutter 安卓 APK 构建环境修通（16:38）
- 阻塞根因（双重）：①系统环境变量 HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:7897（Clash），Gradle wrapper 走代理下载全部超时；②Gradle 发行版 CDN（services.gradle.org 重定向到的海外 CDN）在中国网络直连被重置、走代理也超时 → 报 `Timeout of 120000 waiting for exclusive access to gradle-9.3.1-all.zip` 或 `SocketException 远程主机强迫关闭连接`。
- 修复步骤（已验证可跑通）：
  1. 构建时 `unset HTTP_PROXY HTTPS_PROXY` + `export JAVA_TOOL_OPTIONS="-Djava.net.useSystemProxies=false"`，强制 Java/Gradle 直连。
  2. 把 `android/gradle/wrapper/gradle-wrapper.properties` 的 `distributionUrl` 改为腾讯镜像 `https://mirrors.cloud.tencent.com/gradle/gradle-9.3.1-all.zip`（实测 234MB 可达，直接下载）。
  3. 卡死时清 `~/.gradle/wrapper/dists` 残留锁 + 杀 java 进程（旧 daemon 带旧代理配置被复用会误报 failed）。
  4. 设 `JAVA_HOME=C:/Program Files\Android\Android Studio\jbr`、`ANDROID_HOME=C:/Users/81215/AppData/Local/Android/Sdk`（flutter config --android-sdk 已配）。
- 连通性诊断口诀：`curl -sL --noproxy "*" <url>`（直连）对比 `curl -x http://127.0.0.1:7897 <url>`（代理）；本机直连 dl.google.com / repo1.maven.org 可达，services.gradle.org 的 CDN 重定向目标不可达。
- Maven 依赖（Google/Maven Central）直连可达，无需镜像；仅 Gradle 发行版需换镜像。
- 源码已就绪：姿势引导拍照核心功能（poses/pose_library.dart、shoot/pose_painter.dart、shoot/shoot_page.dart、shoot/photo_preview_page.dart），dart analyze 全绿。
