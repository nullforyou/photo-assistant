## 核心优化策略（结论先行）

1. **英文区保持品牌名不变**：继续用 `Photo Assistant Studio`，避免 Apple 以「名称含描述性关键词 / keyword stuffing」拒审；把关键词密度放到 **Subtitle（30 字符）** 和 **Keywords（100 字符）** 里，风险低、收益高。
2. **中/日/韩区本地化 App Name**：这些市场的用户用本地语言搜索，名称里放核心词（拍照/ポーズ/포즈）能直接提升自然搜索排名，且 Apple 对非英语区名称的 keyword 容忍度更高。
3. **填满所有字符配额**：Subtitle 全部 30 字符用尽，Keywords 全部 100 字符用尽；Description 前 3 行必须出现核心搜索词和品牌卖点。
4. **Promotional Text + What's New 必须填**：Promotional Text 是 170 字符的限时/卖点广告位；What's New 解释「为什么 1.1.0 值得更新/下载」，对排名无直接影响，但影响转化率。

## App Store Connect 提交流程清单

1. **确认 Pricing & Availability**：iOS 1.1.0 版本 → `Pricing and Availability` → App 价格改为 **Free**（已改）。
2. **关联内购**：iOS 1.1.0 版本 → `In-App Purchases` → 勾选 `com.chunyanyang.photoassistant.pro_unlock`。
3. **填 4 语言元数据**：按上文把 `Name / Subtitle / Keywords / Promotional Text / Description / What's New` 分别填入对应语言区。
   - 切换语言：页面右上角选择 `English (U.S.)`、`Simplified Chinese`、`Japanese`、`Korean`。
4. **上传 Review Information**：
   - App Review Information 上传 App 运行截图；
   - `pro_unlock` IAP 页下方的 `App Review Information → Screenshot` 上传**付费墙实际截图**（含标题/说明/价格按钮/恢复购买）。
5. **Add for Review / Submit for Review**：所有标红/必填项完成后，点击 `Add for Review` 提交 1.1.0。
6. **TestFlight 验证**：审核通过后安装 1.1.0 测试版，点击锁定姿势或「解锁全部」按钮，确认付费墙显示真实本地价格并能正常购买（TestFlight 用沙盒，不扣款）。

## 关键词字段解释

- 英文 `Keywords` 共 100 字符，已用满。选择逻辑：
  - 单复数都覆盖：`poses` / `posing`（Apple 不自动处理所有复数变体）；
  - 用户场景词：`selfie`、`selfies`、`portrait`、`model`；
  - 核心功能词：`camera`、`photography`、`composition`、`posture`、`silhouette`、`outline`。
- 中/日/韩关键词同理，避开已在 App Name / Subtitle 中重复的词，把字符预算留给高转化长尾词。

## 为什么不把英文名改成 "Photo Assistant: Pose Guide"

考虑过把英文 App Name 改成 `Photo Assistant Studio: Poses` 或 `Photo Assistant: Pose Guide`，但没有推荐，原因：

- **App Name stuffing 风险**：Apple 近年频繁以「名称包含描述性词汇/关键词堆砌」拒审（Guideline 3.4），尤其英文区审查更严。你之前已经被拒过一次，1.1.0 应优先保证一次过审。
- **品牌连贯性**：公开链接 https://apps.apple.com/cn/app/photo-assistant-studio/... 已经建立 `Photo Assistant Studio` 品牌认知，改名会削弱搜索品牌词的召回。
- **Subtitle + Keywords 足够承载关键词**：把 `Pose Guide` 放到 Subtitle，把 `poses/posing/selfie/...` 放到 Keywords，和直接放 Name 里的搜索权重差距很小，但过审风险显著更低。

> 如果你坚持要强化英文名称关键词，可尝试 `Photo Assistant Studio: Poses`（29 字符），但需承担可能的拒审/来回修改风险。
